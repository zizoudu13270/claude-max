## 5. Deliberately not changed

| item | why |
|------|-----|
| pack and module **UUIDs** | Minecraft matches an installed pack to a world by UUID. Changing them would orphan every world that already has 1.0.2 applied, and nothing about the refactor requires new ones. |
| geometry **bone names** | `part_visibility` in the render controllers matches bones by wildcard (`*rightarm*`, `leftpants4ghq`). A rename cannot be proven complete from the files alone, and a missed reference silently breaks an animation. Kept as-is, as the brief allows. |
| Molang **temporaries** (`t.*`) | Scoped to a single expression; renaming them buys nothing and risks a missed read. |
| obfuscated **string constants** (`'mrdbfl'`, `'bkmptz'`, …) | Enum values compared inside Molang. They carry no previous-project signature, and their writers and readers cannot all be proven found. |
| vanilla atlas keys (`short_grass`, `fern`, `tall_grass_top`, `tall_grass_bottom`, `large_fern_top`, `large_fern_bottom`) | These are Minecraft's own names. The pack overrides them on purpose; renaming them would disable the varied-grass feature. |
| `textures/blocks/fern.png`, `textures/blocks/tallgrass.png` | They replace vanilla files by sitting on the vanilla path. Moving them would silently drop that override. |

## 6. Unresolved references

### 6.1 Item tags that are referenced but never defined

The animation controllers test custom item tags so that modded items can drive the animations. **No item in this add-on defines any of them** — they were meant to be set by items from another pack. They are renamed to the `lbr:` namespace as instructed, but they stay `UNRESOLVED_REFERENCE`: nothing inside this project supplies them.

This is not a fault. Each one is OR-ed with a vanilla test (`q.is_item_name_any('slot.weapon.mainhand','minecraft:shield')` or `minecraft:is_axe`), so vanilla items animate correctly with the tag absent. What the rename does change: an item pack that tagged its items `minerplus:is_sword` no longer matches. Anyone shipping companion items must tag them `lbr:is_sword`.
